# User Profile Page

A clean, modern **user profile page** built with plain HTML, CSS, and JavaScript — no framework required.

## Features

- **Cover photo** with gradient banner
- **Avatar** with click-to-replace file picker
- **Stats bar** — followers, following, posts, projects
- **Follow / Unfollow** toggle with live counter update
- **Tabbed layout** — About · Posts · Edit Profile
- **Inline edit form** — update name, handle, bio, location, and website
- **Toast notifications** for user actions
- Fully responsive down to mobile widths

## Usage

Open `index.html` directly in any modern browser — no build step needed.

```
open index.html
```

## Files

| File | Description |
|------|-------------|
| `index.html` | Page structure and content |
| `styles.css` | All styling (CSS custom properties, responsive) |
| `script.js` | Tab navigation, form handling, avatar picker, follow toggle |
